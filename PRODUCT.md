# Tiny Melo website

A home for Christopher’s apps, tools, and experiments. Visitors can browse the project collection, read project details, learn who is behind Tiny Melo, and follow existing public source links.

The first milestone is a responsive, locally runnable marketing site with actual brand assets, working project dialogs, and a project spotlight carousel. Astro serves the content; GSAP adds progressive motion with reduced-motion support.

Scope excludes accounts, a backend, commerce, analytics, and deployment. Publish only after the project names, statuses, and public destinations have been reviewed.
